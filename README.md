## <img src="https://api.iconify.design/ph:user-bold.svg?color=%2338C2FF" height="24" valign="middle"/> Sobre Mí
Soy **Ingeniero en Sistemas Computacionales** enfocado en el desarrollo de software full-stack y mobile. Me apasiona el diseño de arquitecturas escalables, la optimización de bases de datos y la resolución de retos de lógica algorítmica compleja.

## <img src="https://api.iconify.design/ph:cpu-bold.svg?color=%2338C2FF" height="24" valign="middle"/> Destacados de Ingeniería

* **Ecosistema Institucional Completo (CETIS 27):** Arquitectura masiva de tres capas que incluye un panel administrativo en web, un portal reactivo de comunicación para tutores y una aplicación móvil nativa. Integra un sistema asíncrono para pases de lista dinámicos controlados por escaneo estructurado de códigos QR.
* **Medallista en Hackathons (Tremia):** Acreedor al **3er Lugar en el Innovation Fest** con el proyecto *Tremia*, desplegando un core analítico con Inteligencia Artificial predictiva acoplado a flujos de bases de datos NoSQL con Firebase.
* **Telemetría Full-Stack & Redes (`NetControl`):** Plataforma orientada a la monitorización de infraestructura ISP, enlazando interfaces reactivas en frontend con microservicios asíncronos concurrentes en Python para la orquestación distribuida de pruebas de conectividad y análisis de canales de red.
* **APIs Resilientes en C# (`smartapi`):** API REST robusta diseñada bajo una estrategia tolerante a fallos en cascada de 5 capas (*Remote REST API -> Web Scraping reactivo con Regex -> Offline Cache -> Mapeo Predictivo Estático -> Translation Client*) para asegurar la alta disponibilidad de datos de diagnóstico técnicos.
* **Inteligencia Artificial y Lógica Pura (`Sumo` / `VLSM`):** Entrenamiento y modelado de agentes autónomos usando Aprendizaje por Refuerzo con algoritmos de **Q-Learning** desde cero (`Simulador-sumo`) e implementaciones de alto rendimiento (Java OOP y Python GUI) para el procesamiento matemático de máscaras de red variables de subred (VLSM).
* **Nociones de IoT y Automatización:** Desarrollo de prototipos iniciales para entornos locales utilizando microcontroladores Arduino, orquestación lógica de eventos en Node-RED e integración introductoria con entornos de desarrollo para asistentes virtuales.
